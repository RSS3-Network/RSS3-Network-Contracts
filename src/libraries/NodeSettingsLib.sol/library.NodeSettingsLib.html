exit

Allows a node to exit from the network.

The node must be in a valid state to exit. If the node is registered, initializing, or slashed, its status will be set to "Exited". If the node is online, its status will be set to "Exiting", and the exit time will be set to the current block timestamp plus the node exit period. If the node is in any other state, a revert will occur with the corresponding error message.

function exit(address nodeAddr) external;

Parameters

NameTypeDescription
nodeAddraddressThe address of the node to exit.
